# Dabei sein – für jedes Kind

Onepager für Eltern in der Schweiz: Wie Kinder und Jugendliche trotz knappem Budget an Freizeit, Sport und Kultur teilhaben können – und wo es weitere Unterstützung gibt. Ein Schulprojekt aus Sicht der Gesundheitsförderung.

## Dateien

| Datei | Inhalt |
| --- | --- |
| `index.html` | Seite, Gestaltung und Logik |
| `texte.js` | Alle Texte in 7 Sprachen (de, en, pt, sq, tr, ar, ti) und die schweizweiten Angebote |
| `gemeinden.js` | Lokale Angebote pro Gemeinde (Beispiel: Winterthur) |

## Ändern

- **Text anpassen:** in `texte.js` beim passenden Sprachblock.
- **Neue Gemeinde:** in `gemeinden.js` den Winterthur-Eintrag kopieren und anpassen.
- **Neue Sprache:** in `texte.js` bei `SPRACHEN` eintragen und einen Textblock ergänzen. Fehlende Texte erscheinen auf Deutsch.
- **Link zu einer Sprache:** `?lang=pt` an die Adresse anhängen (z.B. für Elternbriefe oder QR-Codes).

Jede Änderung auf GitHub wird von Vercel automatisch veröffentlicht. Es gibt keinen Build-Schritt.

Die Übersetzungen (ausser Deutsch) sind noch nicht von Muttersprachigen geprüft. Alle Angaben ohne Gewähr, Stand Oktober 2026.
